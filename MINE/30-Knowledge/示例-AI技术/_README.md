# 示例：AI技术

> ⚠️ 示例目录。展示知识库主题目录的组织方式。

## 结构
```
AI技术/
├── 子主题-Transformer/
│   ├── 注意力机制详解.md
│   ├── ViT论文精读.md
│   └── 相关资源链接.md
├── 子主题-分割算法/
│   ├── SegDINO原理.md
│   └── 常见数据集对比.md
└── _README.md  ←（可选）本主题的知识地图
```

## 组织原则
- 一级是**主题/学科**
- 二级是**子主题**
- 三级就是具体的笔记文件
- 笔记之间用 wiki 链接互相关联（如用 Obsidian）
