# 60-Learning/ — 学习材料

> 你正在学或计划学的东西：课程、教程、书籍、论文、技术调研。

## 分类方式：按来源/主题

```
60-Learning/
├── [课程名]/
├── [技术主题]/
│   ├── 教程/
│   └── 代码练习/
├── _Reading/        ← 书籍笔记
├── _Papers/         ← 论文
└── _Backlog/        ← "想学但还没开始"的素材堆积处
```

## 规则
- 用"现在时"判断：正在学的放这里，学完的知识沉淀到 30-Knowledge/
- _Backlog/ 里的东西超过 3 个月没碰 → 删除（你不会学的）
- 一个 git 仓库如果正在学其源码 → 放这里；如果已在项目里用 → 放 10-Work/20-Projects/
