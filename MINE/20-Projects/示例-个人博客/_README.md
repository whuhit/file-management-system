# 示例：个人博客项目

> ⚠️ 这是示例目录，展示个人项目的典型结构。实际使用时删除此目录，创建你自己的项目。

## 结构
```
个人博客/
├── 01-Docs/       设计文档、域名配置说明
├── 02-Code/       博客源码（Hexo/Hugo/Jekyll）
├── 03-Content/    文章内容（Markdown 原文）
└── 99-Archive/    废弃的旧主题、旧文章
```

## 命名规范
- 项目名直接用功能描述：`个人博客`、`量化交易系统`、`微信小程序`
- 内部分区参考 10-Work 项目的编号逻辑，但可以更简单（个人项目通常规模较小）
