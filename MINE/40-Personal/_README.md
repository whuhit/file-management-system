# 40-Personal/ — 个人事务

> 个人生活的行政性事务：财务、保险、证件、医疗、合同、生活记录。

## 分类方式：按事务类型

```
40-Personal/
├── 财务/            ← 账单、报销、税务、记账
├── 保险/            ← 保单、理赔记录
├── 证件/            ← 扫描件（身份证、学位证、合同）
├── 医疗/            ← 体检报告、病历
├── 合同/            ← 租房、贷款、服务合同
├── 生活/            ← 其他生活事务
└── _Archive/        ← 过期事务（旧合同、旧账单）
```

## 规则
- 敏感文件建议加密或放私有云
- 过期事务（如已结束的合同）移入 _Archive/，超 1 年可删
