# 70-Archive/ — 归档区

> 安全网。不敢删、不确定要不要留的东西放这里。心理负担为零。

## 分类方式：按年份 + 来源

```
70-Archive/
├── 2026/
│   ├── from-Work/       ← 工作项目完成后归档
│   ├── from-Projects/   ← 个人项目完成后归档
│   ├── from-Inbox/      ← INBOX 过期清理出来的
│   ├── from-Learning/   ← 学完的材料
│   └── _MaybeDelete/    ← 30天没用过→提醒删除
├── 2025/
└── ...
```

## 规则
- 归档时保留原始文件夹结构
- 不需要精心分类——核心目的是"以后万一要找还能搜到"
- 每年底浏览一次，无用的删除
- _MaybeDelete/ 是你的"冷静期"：放进去 30 天没翻过就删
