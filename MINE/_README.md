# MINE/ — 我管的文件

> 这里放你主动创建、下载、整理的所有文件。
> 不放应用缓存（→SYSTEM）、不放未决策文件（→INBOX）。

## 内部分区（按"关系类型"，不按"内容类型"）

| 区 | 放什么 | 分类维度 |
|---|---|---|
| 10-Work | 本职工作 | 按项目 |
| 20-Projects | 个人项目 | 按项目 |
| 30-Knowledge | 长期知识库 | 按主题 |
| 40-Personal | 个人事务 | 按事务类型 |
| 50-Creative | 创作产出 | 按作品 |
| 60-Learning | 学习材料 | 按来源/主题 |
| 70-Archive | 归档 | 按年份+来源 |
| 90-Misc | 杂项 | 随意 |

## 判断原则
问自己："我现在正在用它做什么？"（现在时，不是将来时）

## 新增分区
编号间隔 10，需要时插入 15/25/35... 不影响已有。
90-Misc 超过 20 个文件时，考虑新增分区。

→ 完整规则见 G:\_INDEX.md
