# SYSTEM/ — 机器管的文件

> 这里放一切"不是你主动创建的"文件：应用数据、开发环境、缓存、软件。
> 核心原则：你不整理它，你只隔离它。

## 子目录

| 目录 | 放什么 | 示例 |
|---|---|---|
| _AppData | 应用数据 | 微信文件、百度网盘下载 |
| _DevEnv | 开发环境 | SDK、依赖库、编译工具、CUDA |
| _Cache | 各种缓存 | HuggingFace、Ollama、pip、npm |
| _Software | 绿色软件 | 非系统盘安装的软件 |
| _VM | 虚拟机/容器 | Docker、WSL 镜像 |

## 规则
- 新的"野生目录"发现时，移入对应子目录
- 移动后修改应用配置指向新路径
- 如果不方便改配置 → 用 mklink 创建符号链接
- 此区的文件你一般不手动管理，让应用自己管
