# INBOX/ — 缓冲区

> 所有新文件的唯一入口。临时中转站，不是仓库。

## 子目录

| 目录 | 放什么 |
|---|---|
| _Downloads | 替代系统下载文件夹（改浏览器设置指向这里） |
| _Scratch | 临时草稿、截图、实验数据 |
| _ToDecide | "不知道怎么归类"的文件（7天上限） |

## 四条铁律
1. 唯一入口：所有新文件先进这里
2. 桌面清零：桌面只放快捷方式
3. 7天上限：_ToDecide/ 超过 7 天必须决策——归类/归档/删除
4. 每周清理：花 10 分钟清空 INBOX

## 清理决策树
- 是项目产出？ → MINE/10-Work 或 20-Projects
- 是知识？ → MINE/30-Knowledge
- 是个人事务？ → MINE/40-Personal
- 是创作？ → MINE/50-Creative
- 是学习材料？ → MINE/60-Learning
- 可能还翻？ → MINE/70-Archive
- 不再用？ → 删除
